# RSE-dropins-2026-7
Files for optional intro to Python course in Michaelmas 2026.

The Python we're using here is in the form of [Jupyter Notebooks](https://jupyter.org/). In the sessions we will import them into Colab using the following method:

- ensure you're logged in to Google and go to [Colab](https://colab.research.google.com/)
- click on 'New Notebook' at the top
- when you have an empty notebook, go to `File > Upload noteobook` and choose GitHub
- you will be prompted to add a URL. Paste in the address for this repo: https://github.com/jonathanblaney/RSE-dropins-2026-7
- choose the relevant week and Colab will automatically discover the Jupyter notebook for the session because of its `.ipynb` file termination
- click on OK and your blank notebook will be populated by what's in the GitHub file
- at this point you can run code and change it, but it will not persist after your session. If you'd like to save your changes go to `File > Save a copy in Drive`.
- you can run this process more than once, so feel free to experiment with the code and try things!
